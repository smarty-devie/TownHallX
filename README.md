# TownHallX\n\n**Version:** 1.0.0\n\nTownHallX brings transparent on-chain verification to mayoral campaigns and municipal referendum cycles. Authorized election officials can register candidates, create referendums, and record votes -- all publicly auditable on the Stacks blockchain.\n\nBuilt with [Clarity](https://docs.stacks.co/clarity/overview) and designed for deployment on the [Stacks](https://www.stacks.co/) network.\n\n---\n\n## Table of Contents\n\n- [Features](#features)\n- [Architecture Overview](#architecture-overview)\n- [Error Codes](#error-codes)\n- [Contract Functions](#contract-functions)\n  - [Administration](#administration)\n  - [Elections (Mayoral Campaigns)](#elections-mayoral-campaigns)\n  - [Referendums](#referendums)\n  - [Read-Only Functions](#read-only-functions)\n- [Installation](#installation)\n- [Testing](#testing)\n- [Deployment](#deployment)\n\n---\n\n## Features\n\n- **Role-Based Access Control** -- A contract owner appoints authorized election officials who can manage elections and referendums. Only the contract deployer can add or remove officials.\n- **Mayoral Campaign Elections** -- Create elections, register candidates with party affiliations, activate voting, and close elections when complete.\n- **Municipal Referendums** -- Pose yes/no ballot questions to voters with transparent on-chain tallying.\n- **One-Vote-Per-Voter Enforcement** -- Each principal can cast exactly one vote per election or referendum. Duplicate vote attempts are rejected on-chain.\n- **Full Lifecycle Management** -- Elections and referendums follow a clear status progression: Pending, Active, and Closed.\n- **Public Auditability** -- All vote counts, candidate registrations, and referendum results are stored on-chain and queryable by anyone through read-only functions.\n\n---\n\n## Architecture Overview\n\n### Roles\n\n| Role | Permissions |\n|---|---|\n| **Contract Owner** | Full administrative control. Can add/remove officials and perform all official actions. Set at deployment time to `tx-sender`. |\n| **Election Official** | Can create and manage elections and referendums, register candidates, and activate/close voting periods. |\n| **Voter** | Any Stacks principal. Can cast one vote per election and one vote per referendum. |\n\n### Status Lifecycle\n\nBoth elections and referendums follow a three-stage lifecycle:\n\n```\nPENDING (u0) --> ACTIVE (u1) --> CLOSED (u2)\n```\n\n- **Pending** -- Initial state. Candidates can be registered (elections only). No voting allowed.\n- **Active** -- Voting is open. No new candidates can be registered.\n- **Closed** -- Voting is finished. Results are final and immutable on-chain.\n\n### Data Maps\n\n| Map | Key | Description |\n|---|---|---|\n| `officials` | `principal` | Tracks authorized election officials. |\n| `elections` | `uint` (election ID) | Stores election metadata: title, creator, status, candidate count, creation block. |\n| `candidates` | `{election-id, candidate-id}` | Stores candidate name, party affiliation, and vote tally. |\n| `election-voters` | `{election-id, voter}` | Tracks whether a principal has voted in a specific election. |\n| `referendums` | `uint` (referendum ID) | Stores referendum question, creator, status, and vote tallies. |\n| `referendum-voters` | `{referendum-id, voter}` | Tracks whether a principal has voted in a specific referendum. |\n\n---\n\n## Error Codes\n\n| Code | Constant | Description |\n|---|---|---|\n| `u100` | `ERR_UNAUTHORIZED` | Caller is not the contract owner or an authorized official. |\n| `u101` | `ERR_ALREADY_EXISTS` | The entity already exists. |\n| `u102` | `ERR_NOT_FOUND` | The specified election, candidate, or referendum was not found. |\n| `u103` | `ERR_ELECTION_NOT_ACTIVE` | The election is not in the required status for this operation. |\n| `u104` | `ERR_ALREADY_VOTED` | The caller has already voted in this election. |\n| `u105` | `ERR_INVALID_CANDIDATE` | The specified candidate does not exist in the given election. |\n| `u106` | `ERR_INVALID_INPUT` | Input validation failed (e.g., empty title or name string). |\n| `u107` | `ERR_REFERENDUM_NOT_ACTIVE` | The referendum is not in the required status for this operation. |\n| `u108` | `ERR_ALREADY_VOTED_REFERENDUM` | The caller has already voted in this referendum. |\n\n---\n\n## Contract Functions\n\n### Administration\n\n#### `add-official`\n\nAdds an authorized election official. The election ID is auto-incremented.\n\n| Parameter | Type | Description |\n|---|---|---|\n| `title` | `string-ascii 100` | The title of the election.
